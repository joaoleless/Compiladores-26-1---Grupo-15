# Grupo 15 - Compiladores 1

Repositório do Grupo 15 da disciplina **Compiladores 1**.

## Projeto

O grupo desenvolverá um **interpretador de Python**, construído a partir das
etapas estudadas na disciplina de compiladores. O projeto deverá contemplar,
entre outras etapas, a análise léxica, a análise sintática e a execução das
estruturas reconhecidas pelo interpretador.
